# PC 練習オーバーレイ（TETR.IO 用）

TETR.IO で **パーフェクトクリア（PC）を続けて取る練習** をするための補助ツールです。
ゲーム画面の上に半透明の「お手本」を重ね、今のミノの並びで組める形と、その後の
消し方を教えてくれます。

> [!CAUTION]
> **免責事項**: このツールは ZEN モードでの **個人練習** のために作ったものです。
> TETRA LEAGUE、QUICK PLAY、カスタムルームなど、他のプレイヤーと対戦する場や
> ランキングに記録が残る場で使うことは想定していません。
> もしこのツールを不正行為（チート）に使い、アカウントの BAN・凍結・記録の抹消などの
> 不利益が生じても、**開発者（Sora3）は一切の責任を負いません**。使用はすべて自己責任でお願いします。

> 開発者向けの詳しい説明は [技術詳細（docs/technical.md）](docs/technical.md)、
> 当初の要求と設計は [仕様書](tetrio_2nd_pc_learning_overlay_spec_v0.1.md) にあります。

## できること

- **画面を見て、今の状況を読み取る**: 盤面、HOLD、今のミノ、NEXT（5 個）を
  画面から読み取ります。ゲームの中身をのぞいたり、キー入力を記録したりはしません。
- **組むべき形（セットアップ）を盤面に重ねて表示する**: 今のミノの並びで組める
  形だけを、ミノの色の薄い塗りで表示します。組めるかどうかは、HOLD 1 枠と
  TETR.IO の回転（SRS+）で、形のミノを下から順に置けるかまで見て決めます
  （例: L を Z の上に乗せる形は、L が Z より先に来て HOLD も使えないなら出しません）。
  - 2 回目の PC（2nd PC）は、Algebruh 氏の資料
    （[`Algebruh's 2nd Methods.md`](Algebruh's%202nd%20Methods.md)）の手順を優先します。
    その資料が扱わない「奇数 JL・T なし」のケース（IJOS など）は、同じ作者の
    [`Algebruh's Bad 2nd.md`](Algebruh's%20Bad%202nd.md) の手順を使います。
  - 7 回目の PC（7th PC）は、Algebruh 氏の
    [`Algebruh's 7th.md`](Algebruh's%207th.md) の手順を優先します。
  - 2 段だけで全消しする **2 ライン PC（2L PC）** が今のミノで取れるときは、
    何回目の PC でも、それを最優先で表示します。2 段の全消しになる 5 個の組は
    `IJLOO`（OOILJ）、`IILLO`、`IIJJO`、`JJLLO` の 4 つだけです。
  - それ以外の PC と、資料に当てはまる形がないときは、公開スプレッドシート
    「Setup Konbini」の形を使います。
  - Setup Konbini の形を出しているときは、その形の PC 率（例: `PC 100.00%`）を
    盤面の左上に表示します。この PC 率は、今の HOLD と NEXT からその形を組んだ場合の
    値です。シートの値は「ID の名前どおりのミノで組み、決まったミノを HOLD に残す」
    前提なので、別のミノで組むと下がることがあり、そのときは状態行に
    `25.00% here (sheet 100.00%)` のように両方を出します。候補はこの PC 率の高い順に並べます。
- **消し方（解）を見せる**: 形が完成したら `S` キーで、残りをどう埋めれば全消しに
  なるかを表示します。自分で考えたいときは押さなければ表示されません。
  解は、画面に見えている HOLD・今のミノ・NEXT だけで組めるものから探します。
  まだ見えていない次のミノまで使わないと全消しにならないときは、次に置く 1 個だけを
  表示します（`a PC stays in 2/2 orders` は、見えていない並びの何通りで全消しが残るか）。
  置くと次のミノが見えるので、そこで解を探し直します。
- **何回目の PC かを数える**: 1 回目から 7 回目までを自動で数え、`R` でやり直すと
  1 回目に戻ります。ZEN の設定で盤面左に PIECES（置いたミノの数）を表示していれば、
  その数から何回目かを決めます（読めないときは自分で数えた番号を使います）。
  状態行に `PC 2 (PIECES 150)` と出ていれば PIECES から、`PC 2 (own count)` なら
  自分で数えた番号です。
  2L PC は 5 個しか使わないので、7 バッグの位置が 4 ライン PC 4 回分進みます。
  そのため 2L PC の後は、PC の番号を 4 つ進めます（例: 1 回目 → 5 回目）。
  Undo（`Ctrl+Z`）で戻しても、番号はずれません。
- **ALL CLEAR の文字が出ている間も次を案内する**: PC を取ると盤面に「ALL CLEAR」の
  文字がしばらく出ますが、その間も盤面は空として読み、次の PC のセットアップを
  すぐに表示します。
- **TETR.IO から離れている間は隠れる**: ほかのウィンドウを手前にすると、お手本は
  消えて読み取りも止まり、キー操作も効かなくなります。TETR.IO に戻ると続きから
  表示します。

## 必要なもの

- Windows
- **TETR.IO Desktop**（ブラウザ版には対応していません）
- ZEN モード、NEXT 5 個表示、ゴースト表示あり

## 使い方

1. TETR.IO Desktop を起動し、ZEN モードを開きます。
2. 設定ウィンドウ（`pc-overlay-gui.exe`）を起動します。
3. 初回と、TETR.IO の表示の大きさを変えたときは **Calibrate board** を押し、
   盤面の左上から右下までドラッグして Enter を押します。
4. **Start overlay** を押すと、TETR.IO の上にお手本が出るようになります。

いまは配布用の実行ファイルを用意していないので、手元で組み立てる必要があります。
Rust を入れたうえで、このフォルダで次を実行してください。

```powershell
cargo build --release
```

組み立てた `target\release\pc-overlay-gui.exe` を、このフォルダから実行します。

## キー操作（オーバーレイの表示中）

キーは TETR.IO が手前にあるときだけ効きます。ゲームへのキー入力はそのまま届きます。

| キー | 動作 |
|---|---|
| `S` | 形が完成した後、消し方を表示する |
| `Ctrl+Alt+S` | 消し方の表示 / 非表示を切り替える |
| `Ctrl+Alt+N` / `Ctrl+Alt+B` | 次 / 前の候補に切り替える |
| `Ctrl+Alt+K` | 2nd PC と 7th PC で、資料の代わりに Setup Konbini の形を使う |
| `Ctrl+Alt+F` | Setup Konbini のデータを取り直す |
| `Ctrl+Alt+1`〜`7` | 何回目の PC かを手で合わせる（数え間違えたとき） |

## 現在の状態

- 主な機能はそろっていて、Setup Konbini の形の表示は TETR.IO で試し、問題は
  出ていません。
- 2nd PC・7th PC の資料に基づく案内、消し方の表示、`R` でのやり直しの検出などは、
  自動テストでは確かめていますが、実際の TETR.IO ではまだ試していません。
- TETR.IO のゲームそのものを再現する仕組み（リプレイと完全に一致するエンジン）も
  作っていますが、まだ遊べる形にはなっていません。
